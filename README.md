# CarSearch 🚗 — מצרף מודעות רכב

אתר שמרכז מודעות רכב יד-שנייה ממספר אתרים ישראליים (יד2, WinWin, Facebook
Marketplace ועוד) לחיפוש אחד. מזינים מאפיינים — יצרן, דגם, טווח שנים, טווח מחיר,
ק"מ, יד, אזור — ומקבלים מודעות מכל המקורות יחד, מאוחדות וממוינות.

## הרצה

```bash
npm start        # מריץ את השרת על http://localhost:3000
# או: node server.js   (אפס תלויות — לא צריך npm install)
```

פתחו את הדפדפן בכתובת `http://localhost:3000`, מלאו מאפיינים ולחצו **חפש**.

## ארכיטקטורה

```
server.js              שרת HTTP (מודול node מובנה) — מגיש את ה-UI ואת /api/search
src/
  aggregator.js        מריץ את כל הספקים במקביל, מאחד, מסיר כפילויות וממיין
  normalize.js         סכמת מודעה אחידה + סינון/דדופ/מיון
  sampleData.js        מאגר דוגמאות ריאליסטי (גיבוי כשמקור חי חסום)
  providers/
    http.js            עוזר fetch עם timeout וכותרות דפדפן
    yad2.js            ניסיון משיכה חי מה-feed של יד2 + נפילה לדוגמאות
    winwin.js          WinWin
    facebook.js        Facebook Marketplace
    auto.js            Auto.co.il (דוגמה להוספת מקור)
public/                ממשק משתמש בעברית (RTL): index.html, styles.css, app.js
```

### הוספת מקור חדש

מממשים אובייקט ספק עם `search(criteria)` שמחזיר את המעטפה הסטנדרטית
(`{ id, name, live, status, message, listings }`) ומוסיפים אותו ל-`PROVIDERS`
ב-`src/aggregator.js`. זהו.

## על נתונים "חיים" מול "דוגמה"

המערכת **מנסה** למשוך מודעות אמיתיות, אבל האתרים האלה מקשים על משיכה אוטומטית:

- **יד2** — חשוף feed ב-JSON, אך מאחורי הגנת אנטי-בוט (PerimeterX). משרת/סביבה
  מבודדת הבקשה בדרך כלל מוחזרת עם `403`. הקוד מנסה, ואם נחסם — נופל לדוגמאות.
- **WinWin / Auto.co.il** — אין API ציבורי מתועד; אינטגרציה אמיתית דורשת גריפת
  HTML שמשתנה לעיתים קרובות.
- **Facebook Marketplace** — דורש התחברות וחוסם גישה אוטומטית; אין API ציבורי
  למודעות רכב. נדרש Graph API עם הרשאות מתאימות או דפדפן מחובר.

כל מודעה מסומנת בבירור: **חי** (ירוק) או **דוגמה** (כתום), וכל מקור מציג את
הסטטוס שלו (חי / דוגמה / חסום / דורש התחברות). כך אפשר להריץ ולבדוק את כל הזרימה —
חיפוש, איחוד, הסרת כפילויות, מיון — מבלי להיות תלויים בזמינות המקור החי.

### להפעלת משיכה חיה אמיתית (הצעדים הבאים)

1. **פרוקסי/Headless browser** למקורות עם אנטי-בוט (למשל Playwright + session אמיתי).
2. **Facebook Graph API** עם token והרשאות, או אינטגרציה דרך חשבון מחובר.
3. **פרסרים ל-HTML** ל-WinWin/Auto עם בדיקות תקופתיות לשינויי מבנה.
4. **Caching** (למשל Redis) כדי לא להציף את המקורות ולעמוד ב-rate limits.

> שימו לב לתנאי השימוש של כל אתר ול-robots.txt לפני משיכה אוטומטית בפרודקשן.
